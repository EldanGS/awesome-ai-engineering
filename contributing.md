# Contribution Guidelines

Thanks for helping make this list better. Please read these guidelines before opening a pull request.

## Adding a resource

- Search previous issues and pull requests to make sure the resource has not been suggested already.
- Add one resource per pull request, in the most relevant section.
- Use this format: `- [Name](https://link) - Short description that ends with a period.`
- Keep descriptions short, objective and free of marketing language.
- Link to the canonical source (official repository, official page), not a mirror or blog re-post.
- Resources must be **actively maintained** (activity in the last 12 months) unless they are canonical references.
- Prefer free resources. Paid resources must be marked with a `$` suffix after the description.
- Do not add your own project unless it is clearly useful and well documented. Disclose affiliation in the pull request.

## Course and certification content

- Learning objectives must be verifiable and map to an exam domain or a real job task.
- Exam facts (number of questions, duration, price, passing score) must link to the official exam page. Mark unknown values as `Unknown` instead of guessing.
- Practice questions must be original. Never copy real exam questions or brain dumps; they violate vendor agreements and will be removed.
- This project is for **learning**. Contributions that automate taking courses, quizzes or exams on someone's behalf will be rejected.

## Pull request checklist

- [ ] Item follows the format above and is alphabetized or placed logically in its section.
- [ ] Link works and points to the canonical source.
- [ ] Description ends with a period and has no trailing whitespace.
- [ ] `npx awesome-lint` passes locally.

## Updating the list

If you notice a dead link, an archived repository, or an outdated certification, please open an issue or a pull request. Retired exams move to the **Retired** subsection with the retirement date.

By contributing, you agree to abide by the [Code of Conduct](code-of-conduct.md).
